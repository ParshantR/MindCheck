About This Tool

📊

Research Foundation

Built on the validated DASS-21 questionnaire using a dataset of 1,812 participants from Daffodil International University, Bangladesh.

🤖

AI Model

N=3 Soft Voting Ensemble combining Gradient Boosting, Random Forest, and a Neural Network — achieving Kappa up to 0.742 (substantial agreement).

🔒

Privacy First

No responses are stored, logged, or shared. Your assessment is processed in memory and immediately discarded.

⚠️

Important Disclaimer

This tool is for informational and research purposes only. It is not a substitute for professional mental health diagnosis or treatment.

REST API

This application exposes a REST API for developers and researchers.

GET /api/health Server health check
GET /api/questions Fetch all 21 DASS-21 questions (shuffled)
POST /api/predict Submit demographics + responses → receive predictions
GET /api/model-info Model architecture + performance metrics
GET /api/feedback-guide Severity level descriptions + helplines
